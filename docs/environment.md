# Рабочее окружение

Эта заметка фиксирует инструменты для учебной работы и команды для быстрой проверки. САПР не включена в базовый набор: её выбирают по модели FPGA-платы.

## Установлено на рабочей машине

- Arch Linux x86_64
- Git 2.55.0
- Icarus Verilog 13.0
- GTKWave 3.3.128
- Java 26
- RARS 1.6: `~/rars1_6.jar`
- Редактор: Zed

Системные версии со временем могут обновиться. Актуальные версии можно посмотреть командами:

```bash
git --version
iverilog -V
gtkwave --version
java --version
```

## Установка базовых инструментов на Arch

```bash
sudo pacman -S --needed git iverilog gtkwave jre-openjdk
```

RARS распространяется отдельным JAR-файлом. Инструкция школы ожидает `rars1_6.jar` в домашнем каталоге; запуск вручную:

```bash
java -jar ~/rars1_6.jar
```

Для базовой работы с UART можно установить `picocom`:

```bash
sudo pacman -S --needed picocom
```

В BGM терминальная программа используется только в упражнениях, где плата обменивается данными с компьютером по UART.

## Плата и САПР

Перед установкой САПР запишите точную модель платы и микросхемы. По ним выбираются Quartus, Vivado, Gowin EDA или OSS CAD Suite. Для Quartus особенно важна поддержка конкретного семейства FPGA. При прошивке под Linux может понадобиться правило udev для USB-программатора.

| Поле | Значение |
|---|---|
| Плата | Заполнить на практике |
| FPGA / семейство | Заполнить на практике |
| САПР и версия | Заполнить после определения платы |
| Программатор | Заполнить на практике |
| Проверка прошивки | Дата и результат |

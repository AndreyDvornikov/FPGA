# Лабораторные

Храните здесь собственные лабораторные и краткие технические заметки. Удобно завести отдельный каталог для каждой темы:

```text
labs/
├── 01-combinational/
│   ├── README.md
│   ├── lab_top.sv
│   └── notes.md
└── 02-sequential/
    ├── README.md
    └── ...
```

Если задание взято из BGM или SVH, добавьте в README лабораторной ссылку на исходный репозиторий и путь к исходному упражнению. Так будет понятно, что именно вы изменили.

После моделирования зафиксируйте в `notes.md`:

- что реализовано и какие допущения сделаны;
- какой тест или команда использованы;
- ожидаемый и фактический результат;
- что осталось проверить на реальной плате.

Большие автоматически созданные каталоги и временные диаграммы в Git обычно не нужны. Если артефакт важен для отчёта, сохраните скриншот или краткое описание в `reports/`.
